# RIA News Parser

Парсер новостей с сайта [РИА Новости](https://ria.ru) по ключевым словам.
Складывает найденные новости в локальную базу SQLite (`News.db`).

## Что делает

- Читает ключевые слова из таблицы keywords базы News.db
- По каждому слову дёргает внутренний поисковый эндпоинт РИА
  https://ria.ru/services/search/getmore/?query=<слово>
- Вытаскивает из ответа ссылки на статьи регуляркой
  (`https://ria.ru/<дата>/...html`)
- Заходит на каждую статью и парсит:
  - время (`time`)
  - заголовок (`title`)
  - текст статьи (`article`) — склеенные блоки article__text
    с вырезанными HTML-тегами
- Складывает всё в таблицу News. Дубликаты по link игнорируются
  (на колонку link стоит `UNIQUE INDEX`)
- Переходит на следующую «пачку» новостей через data-url /
  data-next-url из HTML (пагинация по 20 штук)
